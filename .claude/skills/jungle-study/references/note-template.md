# 노트 양식

`~/study-notes/<주제-슬러그>.md`에 이 양식으로 쓴다. 아직 안 한 단계 섹션은 만들지 않는다. 그 단계를 마칠 때 추가한다. 대화를 옮겨 적지 말고, 나중의 사용자가 5분 만에 다시 떠올릴 수 있는 만큼만 남긴다.

````markdown
# <주제 이름>

- 진행: 1단계 완료 / 2단계 완료 / 3단계 완료
- 처음 공부: YYYY-MM-DD · 마지막: YYYY-MM-DD
- 마주친 상황: <사용자가 말한 상황, 또는 "가정: ○○">
- 기준 버전: <예: Spring Boot 4.0 (3.x 차이는 본문에 표시)> (버전에 따라 다른 주제일 때만)

## 용어

- <용어>: 이게 뭔지 + 어디에 쓰이는지 한 줄 (단계마다 새로 풀어 준 것을 여기에 모은다. 이름만 나오고 풀지 않은 말은 적지 않는다)

## 1단계: 당장 쓰는 핵심

**이게 없으면:** <한두 문장>

**이것만 기억**
- ...
- ...

**최소 코드**
```java
// 돌려 볼 수 있는 가장 작은 예시
```

**일단 넘어간 것** (3단계에서 풀 것)
- [ ] ...
- [ ] ...

**주변 지도**
- <개념>: 곧 필요
- <개념>: 나중에

## 2단계: 현업 정석

**정석**
- <관례>: 왜 정석이 됐나 한 줄

**함정**
- <실수>: 무슨 일이 생기나 → 어떻게 고치나

**의견이 갈리는 부분** (있을 때만)
- ...

## 3단계: 밑바닥 원리

**풀어 둔 빚**
- [x] <1단계에서 넘어간 것>: 한두 줄 설명

**원 출처**
- <스펙·문서·소스 링크>

## 복습 문제 (답 포함, 채팅에는 안 보임)

1. <질문>
   - 답: ...
2. ...

## 실습·퀴즈 기록 (했을 때만)

- <실습 또는 퀴즈>: <결과, 틀리거나 막힌 곳>

## 다음에 팔 것

- ...
````

## `_index.md`

```markdown
# 공부 목록

- [Spring @Transactional](spring-transactional.md): 2단계 완료 · 마지막 2026-10-31 · 다음: 3단계(프록시 원리)
- [HTTP 캐시](http-cache.md): 1단계 완료 · 마지막 2026-10-20 · 다음: ETag와 조건부 요청
```

한 주제에 한 줄. 새 주제는 맨 위에 추가하고, 기존 주제는 그 줄을 고친다.

## `_profile.md`

```markdown
# 학습자 프로필

- Java/Spring Boot 백엔드 개발자
- 잘 아는 것: ...
- 막혔던 것: <주제>에서 <무엇> (YYYY-MM-DD)
- 관심: ...
```

설명 수준을 맞추는 데 쓴다. 새로 안 사실만 한 줄씩 더하고, 틀린 줄은 고친다.
